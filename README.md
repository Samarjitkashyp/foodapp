# 🍔 Crisp & Crave - Restaurant Mobile Application

A modern, production-grade restaurant food ordering mobile application built with **Flutter** (Android & iOS).

---

## 📱 Features

- **Interactive Home & Menu Catalog**: Categorized food items, live banners, special chef recommendations, and real-time search with chips filter.
- **Portion & Addons System**: 
  - Dynamic piece/portion sizes (e.g. 4 Pcs, 1 Portion).
  - Interactive `+` and `-` quantity steppers for addons (e.g. Extra Cheese, Sauces) with real-time price calculation.
- **Cart & Promo Coupons**: Promo codes with instant discount calculations and sticky checkout bar.
- **Order Placement**: Real-time order dispatch to backend API with full customer details, delivery address, and itemized addon tracking.
- **User Account Management**: Order history, delivery addresses, and profile sync.
- **Favorites / Wishlist**: Instant bookmarking of preferred dishes with local persistence.

## 🛠️ Getting Started on Any Computer

Follow these simple steps to run this project on any new machine:

### 1. Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.24+ recommended)
- Android Studio / VS Code with Flutter extension
- Connected Android Device or Emulator

### 2. Clone the Repository
```bash
git clone https://github.com/Samarjitkashyp/foodapp.git
cd foodapp
```

### 3. Install Dependencies
```bash
flutter pub get
```

### 4. Run the Mobile App
```bash
# Run on connected device or emulator
flutter run
```

> **Note**: The mobile app communicates seamlessly with the live production backend API (`https://food.aiaxom.co.in/api/`), so the app works immediately out-of-the-box on any computer or mobile device!
